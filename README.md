# 护理助手 - 刷课助手 (纯原生 Windows 桌面版)

采用 Go 语言 + 原生 Win32 API 打造的纯正桌面刷课工具，专为医院护士打造的“傻瓜式一键操作”。

## ✨ 核心特性

1. **纯原生 Windows 桌面程序**：
   - 彻底告别 Web/HTML 网页与外部浏览器，彻底告别“重定向错误”。
   - 绝不弹黑色 CMD 命令提示符黑框（`-H=windowsgui` 原生窗口编译）。
   - 极速启动、内存占用极低（仅十几 MB 内存），单个绿色 exe 免安装。
2. **极佳老系统兼容性**：
   - 基于标准 Win32 控件，无任何现代显卡或 OpenGL 依赖，全面兼容 Windows 7 / WinXP / Win10 / Win11。
3. **大众傻瓜式三步操作**：
   - **【第一步】连接账号**：支持输入 AccessToken 一键验证，也支持手机号微信验证码登录。
   - **【第二步】选择课程**：下拉框选择培训大课，点击【一键勾选全部未学完】，自动筛出待刷课程；点击表头可切换升序和降序。
   - **【第三步】自动刷课**：点击【开始自动刷课】，带双进度条（总进度 + 当前视频进度）和运行记录，并可导出记录为文本文件。
   - **学习记录**：查看各年度、类别的学分汇总、已学课程和单条课程的成绩明细。
4. **官方粉色“护”字 Logo**：
   - 内置官方图标，任务栏与可执行文件均显示官方粉色 Logo。
